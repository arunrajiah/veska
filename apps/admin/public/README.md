# Static Assets

## Required icon files (PWA)

The following icon files must be placed in this directory for full PWA support:

- `favicon.ico` — browser tab icon (32x32 or multi-size ICO)
- `apple-touch-icon.png` — iOS home screen icon (180x180 PNG)
- `icon-192.png` — PWA icon (192x192 PNG, used by Android / Chrome)
- `icon-512.png` — PWA icon (512x512 PNG, used by Android / Chrome)
- `screenshot-wide.png` — optional install-prompt screenshot (1280x720 PNG)
