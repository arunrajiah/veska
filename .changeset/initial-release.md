Initial public release of @veska/sdk and @veska/cli (v0.1.0).

`@veska/sdk` provides the TypeScript interfaces (`VeskaPluginContext`, `PluginManifest`) needed to build plugins for the Veska platform.

`@veska/cli` provides the `veska create-plugin` scaffolder and `veska dev` command for local development.
