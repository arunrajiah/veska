# Security Policy

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report it privately via [GitHub Security Advisories](https://github.com/arunrajiah/veska/security/advisories/new) (preferred) or email **arunrajiah@gmail.com** with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

We will acknowledge receipt within 24 hours and aim to provide an initial assessment within 72 hours.

## Responsible disclosure

We follow coordinated disclosure. We ask that you:

- Give us reasonable time to address the issue before public disclosure (90 days, extendable by mutual agreement).
- Avoid accessing or modifying other users' data during research.

We will credit researchers in our release notes unless they prefer to remain anonymous.

## Scope

In scope:
- Remote code execution
- Authentication and authorization bypasses
- Privilege escalation (including cross-tenant data access)
- SQL injection or ledger integrity violations
- Secrets exposure

Out of scope:
- Denial of service attacks
- Social engineering
- Physical attacks

## Supported versions

Only the latest release receives security patches. We encourage everyone to stay current.
